# VirtualWork-Internship

This repository contains the `VWL TASK 1.ipynb`, `VWL TASK 2.ipynb`, `VWL TASK 3.ipynb`, `VWL TASK 4.ipynb`, and `VWL TASK 5.ipynb` notebooks for the VirtualWork assignment.

The notebooks include:
- A browser-based port scanner UI built with React-style code.
- A JavaScript-driven email risk analysis UI with pattern detection.
- A file protection and restore demo using a browser-style encrypted token workflow.
- An encrypted file protect/restore UI built with React-style code.
- A Python CLI TCP port scanner implementation for accurate host/port checks.

Use a Jupyter-compatible viewer to open `VWL TASK 1.ipynb`, `VWL TASK 2.ipynb`, `VWL TASK 3.ipynb`, `VWL TASK 4.ipynb`, and `VWL TASK 5.ipynb`.
