# VirtualWork-Internship

This repository contains the `VWL TASK 1.ipynb` and `VWL TASK 2.ipynb` notebooks for the VirtualWork assignment.

The notebooks include:
- A browser-based port scanner UI built with React-style code.
- A JavaScript-driven email risk analysis UI with pattern detection.
- A Python CLI TCP port scanner implementation for accurate host/port checks.

Use a Jupyter-compatible viewer to open `VWL TASK 1.ipynb` and `VWL TASK 2.ipynb`.
